# 조원 2: 기준 레시피의 중간 온도

코드: `code/A_thermal_budget_fps.txt` (수정 없이 그대로)

## 확인하려는 것

기준 레시피의 허용 시간이 측정 범위(10~240분) 안에서 잡힌 온도는 650·700·750 °C 세 개뿐이다. 그 사이 온도를 채워 경계선을 촘촘하게 만든다.

## SWB 파라미터 (이 순서로 입력)

| 파라미터 | 값 |
|---|---|
| Tspike | 1050 |
| Eimp | 10 |
| pai | 0 |
| cdose | 0 |
| Tpost | **675, 725, 775** |

노드 3개, 약 6분.

## 비교 대상 (이미 있는 결과, Xj 허용 시간)

| Tpost | 허용 시간 |
|---|---|
| 650 °C | 226분 |
| 675 °C | 이번 실행 |
| 700 °C | 57분 |
| 725 °C | 이번 실행 |
