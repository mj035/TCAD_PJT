## CSV 열

| 열 | 뜻 |
|---|---|
| node | 노드 번호 |
| pai, cdose, Eimp_keV, Tspike_C, Tpost_C | 그 노드의 파라미터 |
| t_min | 누적 후속 열처리 시간 (분). 0은 spike 직후 |
| Xj_nm | 접합 깊이 |
| dXj_nm, dXj_pct | spike 직후 대비 변화량, 변화율 |
| Rs_ohm, dRs_pct | 면저항과 변화율 |
| dose_cm2 | 실리콘 안의 붕소 총량 |
| active_pct | 활성화율 |
| Rs_tool_ohm | Sentaurus 자체 SheetResistance 값 (교차 확인용) |
